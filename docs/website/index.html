Run from source

1 · Install

Rust 1.85+, Bun 1.1+ and a supported Rust target.

2 · Build

Vite + React + TypeScript + Bun builds the embedded client.

3 · Launch

The daemon listens on localhost by default.

git clone https://github.com/PotenFYR-Studios/OrbyNode.git
cd OrbyNode
(cd web && bun install && bun run build)
cargo run --release -p orbynode-daemon
